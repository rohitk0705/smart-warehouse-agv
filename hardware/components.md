# Components

| Component | Purpose |
| --- | --- |
| ESP32 DevKit V1, 30-pin | Main controller and Wi-Fi |
| AI-Thinker ESP32-CAM | Image capture and MJPEG stream |
| TB6612FNG | Dual DC motor driver |
| Three-channel IR array | Line detection |
| MFRC522 | RFID station identification |
| HC-SR04 | Obstacle distance measurement |
| Servo motor | Rotates the ultrasonic sensor |
| Buzzer | Audible status indication |
| DC gear motors and wheels | Vehicle motion |
| microSD card | ESP32-CAM image storage |

Use a suitable regulated power supply and common ground. Verify motor current,
logic levels, and polarity for the exact modules used in the prototype.
